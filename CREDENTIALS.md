## 7. Account Management, Password Reset & Security Notes

1. **User Onboarding via Admin Console**:
   - Super Administrators and DC Managers can onboard new users directly from the **Users & RBAC** tab in the Admin Console.
   - You can explicitly assign an initial password during onboarding, or allow the system default (`Password123!`).

2. **Self-Service Password Changes**:
   - All onboarded users can change their password at any time via their profile settings modal or when prompted after initial authentication.

3. **Multi-Factor / Session Persistence**:
   - Accounts maintain session persistence with Supabase Auth Application Default Credentials.
